## 2.1 对话详情页

角色对话改为内容详情页布局。聊天区使用播放器式外框，下面显示标题、消息数量、操作栏、角色频道和可展开的角色简介。桌面右侧显示相关角色、这个角色的聊天记录和工具入口。手机端把这些信息放在聊天区下方。

原生聊天区和输入框仍在原来的节点中。页面滚动时只调整外框位置，不搬动、复制或重写消息节点。

- 橙色进度条表示聊天阅读位置，可以拖动定位。
- 向下箭头回到最新消息。
- 宽屏按钮隐藏侧栏并扩大聊天区。
- 专注按钮展开聊天区。再次点击或按 Escape 退出。
- 点赞只记录当前账号对这段对话的操作，不显示虚构评分。
- 收藏角色与首页的收藏同步。
- 导出文本下载当前对话的正文，不包含附件和图片。
- 复制信息只复制角色名、聊天名称和消息数量，不复制聊天正文。

## 按钮与酒馆功能

| 界面位置 | 实际功能 |
| --- | --- |
| 顶部搜索框 | 搜索本地角色的名称、简介和标签 |
| 角色封面和播放按钮 | 打开该角色的原生聊天 |
| 继续上次的故事 | 打开指定的最近聊天文件 |

| 分类和标签条 | 按角色、群组、收藏和本地标签筛选 |
| 信封和聊天记录 | 查看最近聊天，再打开对应记录 |
| 上传角色 | 选择从文件导入，或打开原生新建角色编辑器 |
| 用户图标和菜单 | 用户设定、角色管理、世界书、API、提示词、扩展和酒馆设置 |

| 太阳和月亮 | 手动切换日夜模式 |

账户菜单和页面底部都有外观设置入口。桌面侧栏也可以打开外观设置。

## 日夜模式

支持按时间、跟随系统、白天、夜晚。按时间模式默认在本机时间 07:00 切换白天，19:00 切换夜晚，两个时间都可以修改。

手动选择会保持该模式。重新选择按时间或跟随系统后恢复自动切换。按时间模式每 15 秒检查一次，电脑唤醒或页面重新获得焦点时也会检查。

如果要看到自己选择的背景图片，请在外观设置中关闭使用纯色背景。

## 内容与数据

首页来自当前酒馆账号的真实角色、群组、标签和最近聊天。不添加示例角色，不虚构浏览量、评分和聊天条数。角色较少时卡片不会填满，导入更多角色后会自动排入网格。

聊天记录页读取最近的 200 段记录。收藏保存在本扩展的独立设置中。原生收藏可以在这里显示，但需要在原生角色管理里取消。

搜索、分类和收藏操作不会修改角色卡。聊天正文继续使用原生聊天组件，不改写消息 HTML，不访问内嵌 iframe。新版不会替换或调用其他美化插件的界面。

## 安装与停用

这台电脑已经更新到 2.1，刷新酒馆即可使用。

其他电脑安装时，将完整的 `ph-frame-skin` 文件夹放进酒馆的 `public/scripts/extensions/third-party/`，然后刷新。文件夹中应直接包含 `manifest.json`、`index.js`、`model.js`、`hub.js`、`hub-model.js`、`watch.js` 和 `style.css`。

从主菜单选择停用本款美化，或在外观设置中取消勾选启用。原生工具栏和聊天框架会恢复。要重新启用，可以去酒馆扩展设置中找到 Tavern Hub。

请一次只启用一款界面美化。其他美化的源文件没有修改，设置也保留。
